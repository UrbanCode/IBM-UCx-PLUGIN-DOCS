HCL AppScan 360
===============

HCL AppScan 360 (AS360) is a comprehensive application security testing platform that enables organizations to scan and secure applications. This plugin enables you to use HCL AppScan 360 easily from UrbanCode Build.


Available Steps
---------------

- Create AS360 Presence
- Delete AS360 Presence
- Start AS360 Presence
- Start Dynamic Analyzer AS360 Scan
- Start Software Composition Analysis (SCA) AS360 Scan
- Start Static Analyzer AS360 Scan
- Stop AS360 Presence
